Paramètres GitHub & Système

Configuration du token GitHub pour NixOS

💡
Pourquoi renseigner un token GitHub ?
Sans token, GitHub limite les requêtes à 60 requêtes/heure par adresse IP. Lors des mises à jour ou des synchronisations de configuration NixOS, cela peut bloquer le système avec une erreur 403 rate limit exceeded. Avec un token personnel, la limite passe à 5 000 requêtes/heure.

🔗 Comment générer votre token GitHub :

  1. Rendez-vous sur la page des tokens GitHub : github.com/settings/tokens
  2. Cliquez sur Generate new token ➔ Generate new token (classic).
  3. Donnez-lui une note descriptive (ex: ChomiamOS Nix). Aucun droit spécifique n'est requis pour lever la limite de requêtes publiques.
  4. Cliquez sur Generate token tout en bas et copiez la clé générée (commençant par ghp_).
📁 Enregistré dans /etc/nixos/secrets/github-token.conf (inclus automatiquement par NixOS).
